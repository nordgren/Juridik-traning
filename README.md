# ⚖️ Juridik inför provet

Interaktiv träningsapp i en enda HTML-fil för juridikprovet (gymnasiet).

**Öppna appen:** https://nordgren.github.io/juridik-traning/

## Innehåll

- **Läs**: genomgång av 14 områden med ”Förklara med egna ord” och nyckelpunkter
- **Begrepp**: 100 flashcards, varav bokens 24 rödmarkerade ord
- **Quiz**: 95 flervalsfrågor med förklaringar
- **Sortera**: 16 övningar (ordna, sortera i grupper, para ihop)
- **IRAC**: tre övningsfall med modellsvar
- **Provläge**: blandade frågor med resultat per område

Framsteg sparas lokalt i webbläsaren. Inga beroenden utöver Google Fonts, fungerar på mobil.
